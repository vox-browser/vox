# JPEG XL output dither data

`data/dither_32x32.bin` is the unchanged 1,024-byte blue-noise rank table from
`jxl` 0.7.0 (`src/util/dither_32x32.bin`). Its source attributes the pattern to
**PBBN_32T.png by DZgas (CC BY)**:
<https://gate-dzgas.com/Perfect-best-blue-noise.html>.
The source does not state a CC BY version. No changes were made to the table.

SHA-256: `6247b14297fdc698d699d1e1fa2331e4da69215d852e2493af27009b9effc93e`.
The translated conversion code retains the JPEG XL authors' BSD-3-Clause notice.
