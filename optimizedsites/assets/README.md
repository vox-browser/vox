# Default bookmark favicons

Original favicon bytes bundled for the optimized bookmarks, available offline:

- `wikipedia.ico`: `https://www.wikipedia.org/static/favicon/wikipedia.ico`,
  from the sealed Wikipedia response archive recorded on 2026-11-01.
- `reddit.png`: the original 32×32 favicon already archived in
  `pixel_tests/sites/old-reddit-worldnews/assets/favicon-32x32.png`.
- `vlang.png`: `https://vlang.io/img/v-logo.png`, declared by the site's
  `<link rel="icon">` and fetched on 2026-11-01.

These are the sites' existing marks, not newly generated artwork. Image decoding
and scaling happen through the ordinary browser/native icon paths.
