# Ladybird translation audit: October 20–31, 2026

## Scope and result

Reviewed Ladybird history with **UTC committer timestamps from 2026-10-20
00:00:00 through 2026-10-31 23:59:59 inclusive**. The inventory was taken from
Ladybird history reachable from `9758ed3d17b46ddca55f7080b4f7630c60bcd078`.
Vox's starting revision was `f0a6a7b8e824c18b2c165c53ec6d2a37b1e791eb`.

Commit-message and changed-path screening covered **2,848 upstream commits**.
Of those, 463 touched only paths under `Tests/`, `Meta/`, or `.github/`.
Detailed implementation-diff review concentrated on candidate fixes with a
corresponding Vox implementation. The remaining inventory received metadata
and subsystem screening; this audit does not establish complete parity with
every commit in the date range.

This series translates **87 upstream commits into 71 focused implementation
commits across 72 source files**. The matrix below identifies every selected
upstream SHA and its Vox implementation. Related upstream corrections to one
feature are kept together where their final behavior depends on the chain.

**Tests were skipped at the user's request:** no tests or expected-output
fixtures were added, changed, ported, or executed. Verification consisted of
source review, compiler checks, and patch checks. The managed commit hooks
requested production rebuilds; the builds stopped at their missing-dependency
check before compilation or smoke execution.

## Translation choices

- Match Vox's existing ownership and host boundaries. The XHR timeout change
  keeps deadlines relative to the original send and guards request/controller
  identity across synchronous host callbacks and queued response delivery.
- Use node identity for manual slot assignment and outdent ordering. V's
  reference value comparison is unsuitable for these DOM identity operations.
- Apply WOFF limits while streaming into an explicitly aliased output slice.
  The decoder can retain one fixed delivery chunk beyond the destination limit;
  it cannot grow the destination to an attacker-selected decompressed size.
  WOFF2 table-directory preflight and both native output write paths enforce a
  30 MiB bound.
- Check Wasm supertype depth before canonicalization allocates ancestor arrays.
  Reject malformed multiple-supertype lists at the same boundary so they cannot
  evade that check. Count parameters and locals in `u64` before expansion;
  track `v128` as two operand slots.
- Resolve logical viewport units using the current target's writing axes,
  including font recascading and SVG contexts. Context-free public helpers
  retain their horizontal default because their API has no target context.

The LibJS changes improve the translated V parser and numeric helpers. Vox's
browser execution still uses JavaScriptCore; these changes do not establish
complete LibJS runtime parity. The selected Wasm limits apply to Vox's existing
V parser and validator.
