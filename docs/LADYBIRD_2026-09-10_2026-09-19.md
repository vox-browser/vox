## Translation choices and integration

- Apply HTML's null-namespace attribute rules at both typed DOM models and native
  browser/JavaScript fetch adapters. This includes form actions, base URLs,
  referrer policy, iframe srcdoc, script resource metadata, and image CORS state.
- Preserve document and navigation lifetimes at their existing V boundaries:
  destroyed documents do not arm new timers or change load-delay accounting;
  navigation state is retired before reentrant abort listeners run; replaced
  same-document entries retain their keys and committed promises settle at commit.
- Carry origin taint through the canvas-to-image snapshot used by the native
  canvas bridge. An ImageBitmapCanvasSource cannot silently become origin-clean
  when it originated from a tainted canvas.
- Distinguish opaque URL hosts with a V sum-type alternative and preserve that
  distinction in owned URL copies and CSP serialization. CSP rejects opaque and
  empty hosts while retaining the later numeric-IP matching already translated
  in Vox; the older September domain-only predicate would regress that behavior.
- Preserve sandboxed file-origin capability through DOM/IPC origin serialization
  and inherited about:blank/srcdoc origins. Ordinary opaque data origins remain
  unable to fetch local files. Cache storage excludes response fields that would
  replay cookie or HSTS state.
- Reuse Vox's paint and native backend boundaries. Vertical retained glyphs and
  their shadows share the same clockwise rotation and portable raster transform
  on every platform; horizontal routing is unchanged. Authored highlight colors
  and currentColor metadata travel through style inheritance and typed paint.
- Adapt small runtime changes to V storage: common Math arguments stay inline,
  toFixed has exact word arithmetic for its small-number path, shared DataBlock
  readers snapshot owned bytes, and FFT stages reuse precomputed twiddle factors.

The script changes preserve existing module integrity/referrer/CORS metadata;
they do not add classic-script SRI enforcement where Vox lacks it. The focus
change implements the default same-origin-ancestor allowlist, not a complete
Permissions Policy delegation engine. MP4 edit-list handling implements the
supported first-edit offset semantics, not arbitrary edit-timeline playback.
FFmpeg decoding preserves already produced samples after a corrupt trailing
packet. The V AudioBuffer implementation reattaches acquired channels without an
upstream JavaScript detached-view cache that Vox does not have. The WebDriver
frame-reference predicate correction preserves existing context-handle
serialization; it does not add out-of-process iframe WebDriver hosting.

LibJS changes improve the translated V helpers and runtime. The browser's default
execution remains JavaScriptCore; this series does not establish full LibJS,
site-isolation, shared-memory-agent, or media-decoder parity.

During integration, the changed DOM, parser, script, window, CSS/layout, LibJS,
and WebCrypto owners were reviewed against both parents. The September ports
retain master's newer parser scheduling/nesting, document lifetime, DOMTokenList,
Window named-property, script type-namespace, and crypto/runtime changes. The
CSP host compatibility adjustment above was made in the integration commit.
