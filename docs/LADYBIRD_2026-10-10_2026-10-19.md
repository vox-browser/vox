## Resulting behavior and adaptations

### HTTP, Fetch, and cache

The native transport validates methods, header fields, URL schemes and blocked
ports before starting network access. It removes URL credentials before passing
the URL to curl, disables curl's implicit URL-userinfo authentication, restricts
native protocols to HTTP/HTTPS, and excludes proxy CONNECT headers. The protocol
bitmask options keep compatibility with older system libcurl versions.

Fetch cancellation stops both existing and late-arriving network handles; a
completed PendingResponse releases its one-shot callback. Cache enrollment
snapshots sanitized response headers so trailers cannot later change the cache
selector. The shared cache policy also filters legacy disk-entry headers after
verifying their stored integrity.

Vary keys use canonical names and length framing, distinguish missing and empty
fields, and reject unsupported selectors. The translated memory cache limits
each selector to 32 Vary fields and each URL/method/partition to 16 variants,
using last access for eviction. It chooses the newest matching response before
checking freshness and protects newer variants from older streaming completions.
Client preconditions bypass unconditional reuse; standalone 304 responses are
not stored. Unsafe successful methods invalidate matching GET/HEAD entries;
non-storable replacements retire matching completed and pending producers.

These behaviors are adapted to Vox's in-process memory cache and simpler disk
receipt cache. The 16-variant policy does not implement Ladybird's SQL disk index,
associated-data management, cross-process protocol, or background revalidation.

### DOM, media, layout, and scripts

The branch fixes subtree iterator adoption, cloned document bases, flat-tree
parents, transient MutationObserver bookkeeping and delivery order, reentrant
iframe load muting, load-event delay ownership, and sandbox/unload dialog rules.
Media changes cover initial loadeddata, stable-state removal pauses, replacement
loads started by progress handlers, hidden controls, and MIME aliases.
EventSource consumes a BOM only at the start of a response, including chunk
boundaries, and clears partial per-response parser state on reconnection.

Redirected stylesheets retain the captured original URL as CSSOM location while
using the final response URL for imports, relative resources, and the default
origin-clean calculation. Import-map integrity lookup is limited to Window
globals. Layout and painting changes cover flex sizing, specified-width tables
beside floats, out-of-flow inline edges and pseudo-elements, absent border edges,
invisible backdrop filters, optional round() intervals, and root focus outlines.

The JavaScript changes propagate arrow-function arguments references and reuse
unchanged ASCII case-conversion strings. URL search parameters are rebuilt from
the parsed query, including query-state ASCII newline removal. The storage shelf
reports a stable 10 GiB estimate; existing local/session bottle limits remain.

### Crypto and integration details

The crypto ports normalize generated secret-key usages and correct JWK use,
zero-length KMAC handling, RSA generation bounds, import/derive validation order,
HKDF output bounds, AES-GCM parameter order, ML-DSA context size, and Argon2 byte
alignment. Generic SubtleCrypto key/usage validation remains before normalized
algorithm dispatch. Early exchange-curve validation is limited to X25519; X448's
existing error order is preserved. The round() integration similarly leaves
dimension/percentage validation to the common calculation type check.

Screen geometry is reported in CSS pixels, precise wheel events preserve their
legacy delta scaling, and navigator.platform uses browser-compatible OS tokens
and kernel architecture spelling.

The retained worker adaptation limits dedicated/shared process starts to 64 for
one top-level origin **within the current process's host registries**. It is not
a global per-site/session quota: cross-process and nested-worker quota accounting,
same-site aggregation, private-session separation, and exiting-process grace
accounting are absent. The current worker runtime does not install WorkerHost;
no currently exposed nested-worker bypass is asserted. Opaque-origin identity is
preserved in the quota key. This is not complete upstream worker isolation or
process-exhaustion protection.

## Already represented and deferred work

- Browser history already filters recorded and loaded entries to HTTP, HTTPS,
  and file schemes ([8167e64c1988](https://github.com/LadybirdBrowser/ladybird/commit/8167e64c1988)).
- Worker scripts and modules already use fixed UTF-8 decoding without UTF-16 BOM
  sniffing ([077dbb375bd8](https://github.com/LadybirdBrowser/ladybird/commit/077dbb375bd8)).
  Manual slot reassignment already removes nodes from their old slot
  ([09aaa250e3ad](https://github.com/LadybirdBrowser/ladybird/commit/09aaa250e3ad));
  text controls already clamp both selection endpoints after value changes
  ([844749b48601](https://github.com/LadybirdBrowser/ladybird/commit/844749b48601)).
- Vox's cached Node.index(), typed bytecode records, bounded native-function
  lookup, and iterator failure handling already provide some of the behavior
  behind upstream optimizations and safety changes. These are comparisons of
  the existing implementation, not new port credit.
- **Authoritative local-file isolation remains deferred**
  ([d0cbf9c4c584](https://github.com/LadybirdBrowser/ladybird/commit/d0cbf9c4c584)).
  Direct ResourceLoader reads and ordinary Fetch origin checks do not provide
  upstream's UI-owned capabilities, blob provenance, admitted-navigation state,
  and descriptor broker. The full worker quota also remains deferred beyond
  the limited host-registry adaptation above.
- Clipboard, popup, and external-link hardening needs a trusted UI input ledger
  and corresponding privileged broker endpoints. Download quarantine and
  user-initiated file opening await implemented download-file/open lifecycles.
- Larger translations remain deferred: Rust JIT/tiering and GC internals,
  coupled CSS sizing/invalidation series, SVG SMIL and integrated geometry/text
  queries, text fragments, AudioServer/native media processes, picture-in-picture,
  and broader cross-process navigation/history protocols. Some of these groups
  received message-level triage only. Existing inactive-script guards are not
  claimed as the complete callback-realm/destroyed-subtree upstream changes.
