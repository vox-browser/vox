# Ladybird → Vox: 2026-10-10 through 2026-10-19 (UTC)

## Scope and method

Scanned the commit subjects in `LadybirdBrowser/ladybird` for the **inclusive ten-day UTC range**, paging through every day rather than relying on a single page. Inspected the upstream source patches for selected behavior changes, then compared them with the corresponding V implementations in `vox-browser/vox` before porting. Changes have been **translated into V**; no C++ or Rust upstream code was copied wholesale.

## Considered but not copied

- **Already implemented or equivalent in V:** the synchronous CSP check for timer strings ([e82ab9a823cf](https://github.com/LadybirdBrowser/ladybird/commit/e82ab9a823cf)); clamping both ends of a changed text-control selection ([844749b48601](https://github.com/LadybirdBrowser/ladybird/commit/844749b48601)); constant-time HMAC verification; and UTF-8 `Body.text()` decoding.
- **Different architecture:** JIT/GC optimizations, C++/Rust implementation cleanups, native request-server retry handling, disk-cache index/schema migrations, and Qt pixel-geometry wiring have no safe one-line V equivalents. The V cache keeps in-memory string keys and has no corresponding disk format to migrate.
- **Larger follow-ups, not partial cherry-picks:** text-fragment directives, broader cross-document navigation/lifecycle changes, CSS style invalidation and the newer SVG animation APIs require coordinated work. The specific redirected-stylesheet and iframe-reopen cases have now been translated as documented in the expanded section.

## Screening exclusions and open implementation work

The inventory scan covered all 1,360 commit subjects, but it was **not a
line-by-line correctness audit of all 1,360 upstream diffs**. We examined
candidate implementation patches in detail where Vox had relevant code.
Therefore neither the count screened nor this matrix establishes complete
upstream parity.

- **Already present in Vox:** overscroll-behavior parsing and scroll chaining, several SVG geometry helpers, synchronous CSP checking of string timers, selection clamping, and constant-time HMAC verification.
- **Deliberately larger deferred work:** the coordinated SVG SMIL motion animation series; text-fragment directives with per-navigation authorization and rendered range search; broad CSS style-engine refactors; iframe site/process isolation; custom-property animation dependency chains; native AudioServer; and the LibJS Rust JIT/GC/bytecode tier.
- **Host mismatch:** upstream Qt widget edits, Rust FFI cleanups, and native disk-cache schema/index migrations need distinct V implementations; they cannot be cherry-picked. The worker cap approximates upstream's process policy using Vox's current ownership model.

Source review and GitHub patch inspection were used; **compilation and browser
behavior remain unverified**. **No tests or test fixtures were added, modified,
or run**, as requested.

## Verification boundary

Per request, **no tests were added, modified, or run**. No build or compiler run was performed in this connector-only checkout workflow.
