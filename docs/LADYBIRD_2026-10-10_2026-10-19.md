# Ladybird → Vox: 2026-10-10 through 2026-10-19 (UTC)

## Scope and method

Scanned the commit subjects in `LadybirdBrowser/ladybird` for the **inclusive ten-day UTC range**, paging through every day rather than relying on a single page. Inspected the upstream source patches for selected behavior changes, then compared them with the corresponding V implementations in `vox-browser/vox` before porting. Changes have been **translated into V**; no C++ or Rust upstream code was copied wholesale.

## Considered but not copied

- **Already implemented or equivalent in V:** the synchronous CSP check for timer strings ([e82ab9a823cf](https://github.com/LadybirdBrowser/ladybird/commit/e82ab9a823cf)); clamping both ends of a changed text-control selection ([844749b48601](https://github.com/LadybirdBrowser/ladybird/commit/844749b48601)); constant-time HMAC verification; and UTF-8 `Body.text()` decoding.
- **Different architecture:** JIT/GC optimizations, C++/Rust implementation cleanups, native request-server retry handling, disk-cache index/schema migrations, and Qt pixel-geometry wiring have no safe one-line V equivalents. The V cache keeps in-memory string keys and has no corresponding disk format to migrate.
- **Larger follow-ups, not partial cherry-picks:** redirected stylesheet resource location, fragment text directives, cross-document navigation/lifecycle changes, broader CSS style invalidation and layout changes, and the newer SVG geometry/animation APIs require more integrated translation than fits this focused compatibility batch.

## Verification boundary

Per request, **no tests were added, modified, or run**. No build or compiler run was performed in this connector-only checkout workflow. Changes were reviewed against the upstream diff and the existing V call sites; compilation and browser behavior remain unverified and are appropriate review steps before merging.
