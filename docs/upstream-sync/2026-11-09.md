## Material boundaries and deferred work

- Layout, native JavaScriptCore host and main-module execution remain blocked
  by the base revision's undefined `grid_lanes_definite_repeat_item_size`.
  This batch does not supply a guessed grid-lanes sizing algorithm. The draft
  PR needs the base build restored and its blocked regressions run before it
  can claim complete validation.
- The new clipboard permission rules are connected to the translated
  `Clipboard`/`SystemClipboardBackend` API. Vox still lacks a functional
  `navigator.clipboard` host bridge; these are native model tests, not a claim
  of end-to-end browser clipboard integration.
- Opaque buffered-body consumption avoids an unnecessary accumulator copy,
  but Vox's `Body.bytes()` still makes one owned clone. For imported CSS, the
  native adapter lacks redirect-taint metadata and conservatively disables
  the same-origin quirks MIME exception. The policy does not infer taint from
  a same-origin final URL.
- Grid changes include definite-height/aspect transfers and alignment, but
  not the complete row-to-column intrinsic sizing feedback pass. SVG fitting
  covers raster masks/patterns and ordinary nested SVG painting; a nested
  vector image in the flattened mask/pattern stream still needs a clip
  operation for full `slice` parity. Whole-word double-click works across
  inlines; the absent DOM word-drag continuation owner remains deferred.
- Full SameSite context propagation, filtered preload consumption and
  sandboxed out-of-process iframe placement require additional native
  transport/frame ownership. Existing cookie parsing or sandbox bits alone
  do not provide those guarantees. TLS group selection needs a backend-aware
  curl/OpenSSL adapter. Frameset layout and descriptor/axis-aware font
  synthesis also lack required owners.
- The Hub/Qt process split, the new Rust engines and their GC/JIT/FFI changes
  are not copied into Vox's different native V/JavaScriptCore architecture.
  Each commit records the specific owner or missing prerequisite below.
