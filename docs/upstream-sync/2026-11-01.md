# Ladybird November 1, 2026 audit and V ports

## Scope

Reviewed all **149 commits** on `LadybirdBrowser/ladybird` whose **committer
timestamp** is within **2026-11-01 00:00:00–23:59:59 UTC**. Author timestamps
are deliberately not used: several changes were authored on October 31 and
landed on November 1. The GitHub commits API returned two pages (100 + 49),
and every commit's changed files and patches were reviewed. The first and last
committer timestamps are 00:10:34 and 23:49:30 UTC.

Vox baseline: [`f0a6a7b8e824c18b2c165c53ec6d2a37b1e791eb`](https://github.com/vox-browser/vox/commit/f0a6a7b8e824c18b2c165c53ec6d2a37b1e791eb).
The ports adapt behavior to Vox's existing V owners. They do not import
Ladybird's Rust/C++ backend or change the browser's JavaScriptCore default.

| Decision | Commits |
| --- | ---: |
| Ported into existing V implementations | 18 |
| Existing behavior or implementation already covers the change | 11 |
| Specific to an upstream backend, UI, build, or test harness absent in Vox | 50 |
| Deferred because a coordinated subsystem change or measured performance work is needed | 70 |
| **Total** | **149** |

“Deferred” includes useful future work; it does not mean the upstream change
has no value. Supporting DTD entities, high-resolution SVG canvas rasterization,
4-GiB array buffers, Latin-1 string storage, compressed heap pointers, compositor
wheel routing, fragment/run-cache layout, shared-worker extended lifetimes,
and structured DevTools output all need more than a local patch in Vox.

## Validation

Used Vox's pinned V compiler, `f7f3add7af3c4615ba5dbedc06e18f76ef604346`
(`V 0.5.2 f7f3add`), with the C backend and `-memory-limit 10G`.
Compiler and native-test processes ran through `tools/run_memory_bounded.py`;
test execution used a separate 3-GiB budget. The compatibility fallback was
disabled with `V_MACOS_V3_NO_FALLBACK=1`.

| Check | Result |
| --- | --- |
| LibJS array iterator, canonical index, typed-array find/reduce/search/source suites | **27 test functions passed with default Boehm GC and again with `-gc none`: 54 successful test-function executions.** All 12 compilations and all 12 test binaries exited zero. |
| SVG use lifecycle and standalone nested-backface test files | V `-check` passed. This is a type-check result, not a native runtime pass. |
| DOM and painting native tests | Native compilation was blocked by unavailable browser development dependencies. After building the real ICU-backed platform archive and WOFF2-backed font archive, the remaining native compilation stopped at missing `hb.h` (HarfBuzz headers). No DOM or painting test bodies ran. |
| Five focused layout test files | Checking stopped at the existing call to undefined `grid_lanes_definite_repeat_item_size` in `layout/grid_formatting_context.v:354`, plus two consequent type errors. The same undefined call exists at the baseline above; no layout test bodies ran. |
| XMLSerializer and error-information tests | Isolated `-no-parallel -check` retries were killed by the environment (signal 9, wrapper exit 137), with sampled peak process-tree RSS about 7.97 GB each. These checks did not complete, and the HTML test bodies did not run. |
| Canonical production rebuild | The managed hooks requested rebuilds after the implementation commits. An explicit `--build --backend c --prod` attempt stopped in dependency preflight at missing `javascriptcoregtk-4.1`; no production browser binary was produced. |
| Patch hygiene | `git diff --check` passed. New test files and the focused XMLSerializer/error-information edits passed formatter checks. |

LibJS suite sizes are 6 array-iterator, 2 canonical-index, 4 typed-array-find,
5 typed-array-reduce, 5 typed-array-search, and 5 typed-array-source tests.
The large-index regressions reserve virtual address space and touch only the
few elements needed for early-exit assertions; they do not initialize a
multi-gigabyte buffer. ICU 76.1 runtime libraries and matching official ICU
headers supplied the real Unicode dependency. No stub native libraries were
used to obtain passes.

On a provisioned Vox checkout, reproduce each focused LibJS suite with the
following pattern, adding `-gc none` for the second build and substituting
the other five test files. Keep compilation and test execution under their
respective memory guards:

```sh
python3 tools/run_memory_bounded.py --lock Build/nov1-compile.lock \
  --report Build/nov1-compile.json --timeout 600 -- \
  "$V_BIN" -b c -cc gcc -memory-limit 10G -enable-globals \
  -skip-running -o Build/nov1-array-iterator libjs/array_iterator_test.v
python3 tools/run_memory_bounded.py --lock Build/nov1-run.lock \
  --report Build/nov1-run.json --limit-gib 3 --timeout 120 -- \
  Build/nov1-array-iterator
```

Run the DOM, HTML, painting, and layout regression files in this change on a
checkout with the complete native development dependencies and the baseline
layout helper restored. Full browser build, rendering screenshots, and
browser-wide performance remain unvalidated. Keep the pull request in draft
until those remaining checks can run.
