is used for the PR. No shared branch or canonical user-machine checkout was
rewritten.

### Integration limits

EventSource currently has a translated model and a public `EventSourceFetchHook`,
with no production browser binding/network adapter found. The optional final
response URL is consumed by its existing `receive_response` path and preserves
compatibility for direct callers that omit it. These ports improve that model;
they do not add browser EventSource exposure.

The sort change affects the translated `libjs` implementation. Vox's default
browser scripting backend remains JavaScriptCore. Tab changes cover per-tab
arithmetic and glyph/code-unit accounting; they do not claim the later
soft-wrap/float/indent tab-origin work listed below. No performance speedup is
claimed from source review alone.

matching owners existed; mechanical translations were excluded. Media source
selector lifetime work also needs a persistent selector/state model rather
than Vox's current captured URL/type arrays.

The selected changes are therefore a bounded correctness batch with explicit
follow-up work, rather than a claim of complete upstream parity.
