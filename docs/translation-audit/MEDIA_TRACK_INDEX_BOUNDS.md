# Bound audio/video track indices before conversion

The typed indexed-property adapters for `AudioTrackList` and `VideoTrackList` now require a numeric value within `[0, length)` before converting it to `u32`, then check exact integrality. Previously, large integral values such as `2^32` could narrow to slot zero, and NaN or infinities reached an unsafe floating-point-to-integer conversion. Valid indices retain track identity, including negative zero selecting slot zero. Nonnumeric values keep their existing rejection behavior.
