# Live playback-clock position observation

The playback-position observer now compares and records a sample from `current_playback_position()` instead of the cached model scalar. It takes that comparison/cache sample after the playback-manager and seeking guards. The first observation seeds the last-known position, an equal observation returns without media tasks, and a changed live position enters the existing time-marches-on, ended-state, video-dimension and queued buffer-monitoring paths. A stale model scalar can therefore neither hide real clock movement nor fabricate a change when the live clock is stationary.
