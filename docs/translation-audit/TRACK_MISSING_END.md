# Skip track cue blocks that lack an end timestamp

A translated text-track resource with an empty end-timestamp field now skips that malformed cue block instead of indexing an empty token list and panicking. This includes a timing line ending immediately after the arrow, whitespace-only right-hand sides and an empty first right-hand side before another arrow. Valid cue blocks elsewhere in the resource continue through the existing parser.

The parser now stores the end-field list, checks that it contains a token and only then reads its first element. A malformed block is skipped through the existing block loop. Resources accepted by the existing signature check can consequently complete with zero cues or with their remaining parsed cues, using the normal loaded state and load event. Network failures, unsuccessful response status and signature rejection retain their error path.
