# Clear text-track cues when the source changes

Changing a translated HTML track's null-namespace `src` now immediately empties its existing cue list. Previously, a successful replacement appended its cues to those from the old resource, while empty, invalid and failed replacements could retain the old resource's cues. Every source assignment clears first, including an unchanged string or a different spelling of the same resolved URL. Source removal clears as well.

`TextTrack.clear_cues()` keeps the existing `TextTrackCueList` object, so retained list aliases observe the emptied list through indexed and identifier lookup. It removes each cleared cue's track association only when that association still points to this track. A cue also retained by another list keeps its actual owner's association. Detached cue objects keep their identifier, timing, text and event handlers, and the track keeps its metadata, mode, readiness state and handlers. Clearing itself does not dispatch events or notify readiness observers.

`HTMLTrackElementModel.set_src()` clears before storing, parsing or selecting the new source. The DOM attribute callback also clears on removal, before the existing absent-value return. Removing `src` therefore retains the previous model source and selected URL without starting another fetch or resetting readiness. The existing equal-URL guard likewise suppresses duplicate fetching after the list has been cleared. A changed URL can synchronously install only the newly fetched cues through the existing controlled fetch path; an empty or invalid URL remains empty through the existing error transition and can recover on a later source.

The compact browser replays explicit track source writes even when their text equals the current attribute. Its ordinary snapshot reconciliation continues to suppress unchanged values, so an unrelated mutation or a later finalization does not clear a newly loaded list again. Replay is limited to actual HTML track elements and uses the selected qualified-name attribute's namespace and identity; foreign-namespace attributes do not enter the content-attribute hook. The generic compact facade remains the browser entry point. This slice adds no native HTMLTrackElement JavaScript binding and changes no code in `browserjs/document_bridge.v`.
