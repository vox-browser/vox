# Live video poster paint facts

Replacing a video's poster with an image of the same size now refreshes its retained paint data and cached display-list commands. Previously the HTML model changed while subsequent paint commands kept the old poster. Empty, failed and removed posters also switch the retained representation to transparent black when the natural size stays unchanged. Metadata updates refresh the paintable's natural media size with an immutable replacement geometry snapshot, preserving older display lists.

The change follows upstream `963d46a829f3e1b79f44dba9d02afb70654300fa`, `HTML/HTMLVideoElement.cpp::update_natural_dimensions` and `Painting/PaintFacts.cpp::push_video_paint_facts`. Upstream pushes facts on both the equal-size and size-changing paths. The V renderer installs an optional HTML-to-painting callback when it materializes a video's paint transport. Each push resolves the element's current document and layout handle, compares representation, poster identity, video source identity and natural media size, updates the matching retained video box, invalidates that box's phase cache and requests a paint-command-only repaint. Identical facts keep the cached display list; hit testing, paint order and layout geometry remain retained for equal-size updates. Adoption and a temporarily missing layout box do not retain a captured old document or layout owner. The callback adapts the upstream Rust-arena slot update to this renderer's BlockBox transport. The V transport also keeps its cached natural-media geometry current while a poster is displayed; upstream poster-only arena facts do not carry that field. Such metadata-only changes can request an additional repaint in this adaptation.
