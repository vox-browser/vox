# Media readiness while the network is empty

`set_ready_state()` now returns before readiness-event substeps whenever the network state is `NETWORK_EMPTY`. It still assigns the readiness state, invalidates buffering-related style, and preserves the deferred ended and screen-wake-lock maintenance that precedes the guard. Empty-network readiness drops therefore no longer dispatch the legacy `waiting` event or enter its synchronous listener, and the existing first-data state and document load blocker remain intact until an eligible nonempty transition.
