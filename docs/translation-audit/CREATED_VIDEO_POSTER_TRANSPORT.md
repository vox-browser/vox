# Poster transport for script-created native videos

Feature `26df223ebde93e144899d8630f06ffdfc1518098` supplies the existing native poster transport to HTML video owners created by the compact media binding. Previously only page-installation discovery configured video poster hooks; a later `document.createElement("video")` obtained native media state but no poster decoder or Fetch host. Its first poster write could therefore leave the image empty.

`MediaElementHost.create_with_created_element_hook` accepts an optional embedding callback, invoked once after a fresh native owner enters the host's identity map and before its first attribute replay. The existing `create` API delegates with no callback. The native shell extracts its existing per-video host/decoder setup and supplies it through this boundary. It filters audio and foreign namespaces, uses genuine document settings for typed Fetch, and retains the URL decoder when the process host is unavailable. The callback installs inputs without fetching or rewriting an attribute. Parsed-owner discovery remains responsible for initial parsed posters; binding or replaying existing owners does not repeat that setup or restart their requests.
