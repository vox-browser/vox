# Forward playback rates to the typed media manager

`HTMLMediaElement.set_playback_rate()` now forwards each accepted value to an attached manager through `MediaPlaybackManagerHooks.set_playback_rate`. The stored double and any queued `ratechange` notification commit before the callback. The backend argument is a float, matching upstream's explicit `static_cast<float>`. Accepted equal values still reach the manager without another event; unsupported values leave the field, queue and backend untouched. The default playback-rate setter remains independent of the current backend speed.

Attaching or replacing the manager hooks initializes the current rate after marking that manager present. Resource manager setup likewise installs the current rate. While the manager is absent after resource teardown, setters update the double and retain their existing event behavior without invoking a stale backend hook. A later setup applies that latest value. Reentrant backend setters retain their inner value because no state is written after the callback.
