The caller collects actual committed, scrollable DOM ancestors in source order and obtains the target's client rectangle once. For each ancestor it checks the actual document origin, computes the position with the existing source helper, then projects the rectangle by the current offset minus the clamped destination. It clips a nonempty intersection against the actual transformed padding box before computing the outer ancestor's position. The rectangle intersection follows `LibGfx/Rect.h::intersected()`.

Element and viewport scrolling forward behavior to the actual owning Navigable operations. The caller retains their real WebIDL capabilities and stops after the source shadow-including container check.
