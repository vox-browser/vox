# Source wrapping integer arithmetic and bitwise operators

Source pin: `963d46a829f3e1b79f44dba9d02afb70654300fa`.
Reviewed: 2026-10-04. Tooling: `8eca94c1`; implementation/tests: `54308045`.

The Add, Subtract, Multiply, BitAnd, BitOr and BitXor records generated by
`Operators.h::DEFINE_BINARY_OPERATOR` translate to twelve concrete scalar
functions in `webassembly/operators_arithmetic_integer.v`. They retain the
actual types from `BytecodeInterpreter.cpp:906–995,1068–1157`: arithmetic
uses u32/u64 operands for defined wrapping, then i32/i64 PushType; bitwise
operations use signed i32/i64 operands and results.

The generator's `--family arithmetic` extracts the exact Source macro body
and invocation lines with SHA-256 hashes, and compiles against actual AK
headers. **1,728 exact native C++ results** cover all twelve functions at
signed/unsigned boundaries, including unsigned overflow and i32 truncation.
The preceding 2,880-case comparison fixture remains byte-exact after the
shared macro extraction change.

The new file passes default GC privately. It and comparison/helper neighbors
pass **3/3** privately and **3/3** canonically with GC disabled
(`Build/audit-fixes/source-arithmetic-integer-canonical-gc-none.log`). The
second test uses actual Configuration registers and the Source numeric helper
to verify unsigned wrapping, signed PushType records, cleared high bits,
preserved RHS/separate destination and unchanged operand stack.

This adds the 86th package test file; the previous clean 83-file private sweep
predates shifts, comparisons and arithmetic. No full 86-file sweep or
production opcode interpreter is claimed. Floating/SIMD operations, native
compilation, instantiation and collector ownership remain open.
