# Native media loop reflection

The setter checks its receiver, applies WebIDL ToBoolean, replays pending DOM changes, then sets loop to an empty string or removes it. ToBoolean does not call author conversion hooks, including for objects and revoked proxies; an omitted argument becomes false. Replay exceptions retain their JavaScript identity, and closed runtime/host guards prevent further binding access.

Parsed video and script-created audio retain their real DOM owners; ordinary and SVG elements do not receive the native accessor. Reflection itself does not fetch, change volume, or start playback.

The V model reads loop from its associated DOM element, including after direct attribute mutations and adoption, while ownerless models retain the existing boolean fallback. The actual endpoint algorithm captures that live presence into loop_was_specified_at_end_. Active looping seeks to zero without pause or ended events. Its paused guard prevents a seek for paused looping media. Adding loop after a non-loop endpoint does not revise that captured decision. The existing completion task dispatches timeupdate, then rechecks the live position, playback direction and paused state before conditionally pausing; it subsequently fires ended. A timeupdate callback can change the position and prevent that pause. The cached ended value continues to follow the existing event-loop boundary.
