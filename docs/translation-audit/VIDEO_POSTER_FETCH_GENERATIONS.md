# Superseded video poster requests

A video poster fetch that is superseded during a synchronous host callback can no longer overwrite a newer frame or erase it after reporting an older failure. Clearing the poster, assigning an empty or invalid URL, or completing a newer failed fetch also prevents an older success from restoring obsolete pixels. Every invocation receives a new generation before parsing or clearing; successful and failed fetch completions check that generation before changing the poster frame, natural dimensions or published paint facts. The previous frame stays available while the current synchronous fetch runs.

This adapts step 1 of upstream `963d46a829f3e1b79f44dba9d02afb70654300fa`, `HTML/HTMLVideoElement.cpp::determine_element_poster_frame`: a new invocation supersedes the existing algorithm without clearing its poster first. Upstream stops a fetch controller and uses asynchronous response/body/decode callbacks. This slice adds generation protection around the translation's existing synchronous bitmap fetch hook. It establishes no asynchronous cancellation, request metadata, body/decode scheduling or obsolete asynchronous response protection.
