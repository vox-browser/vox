# Enough-data media autoplay

Automatic playback now begins in the `HAVE_ENOUGH_DATA` readiness transition. Finishing a resource fetch with only metadata or future data leaves it paused. The transition first queues `canplaythrough`, checks live autoplay eligibility and the owning document's playback policy, then clears paused state. When a poster is shown it clears the poster and runs the normal time-marches-on path, before queuing `play` and notifying about playing. This internal path preserves `can_autoplay` and creates no public `play()` promise.
