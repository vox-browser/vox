# Video poster load-event delay

Poster fetching now delays the video element's actual node document through the synchronous image-fetch/decode hook. Completion or failure releases that poster blocker before publishing natural dimensions. A superseding invocation releases the obsolete blocker, including when the new poster is removed, empty, invalid, or has no host fetch hook. Existing generation checks keep obsolete completions from changing the current poster or releasing later work.

The existing media adoption callback also retargets an active poster blocker to the new document. It does nothing when no poster fetch is active. The media resource-selection delay and unrelated document blockers remain independent.
