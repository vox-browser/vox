Pinned `AbstractMachine.cpp:355–382` checks destination offset, destination count, source offset and source count before zero-count/same-offset shortcuts and the overlap-direction branches. The V assertions were removed in production. A real empty buffer with destination offset 1 and count 0 returned through the zero-count shortcut without enforcing Source VERIFY. `Build/audit-fixes/source-memory-move-data-guard-original-production-gc-none.log` records this safe, zero-access failure:1/1 FAIL in 11.788 s.

Compiled subprocesses exercise every fatal category, including invalid source offset with zero count and invalid count with equal offsets. Real cage memory tests cover empty, exact-end and same-offset operations, both overlap directions, disjoint exact-end moves and unchanged neighboring bytes.
