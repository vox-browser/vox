Hello! I’m a software engineer and I write here about free and open source software, politics, ethics, and philosophy. I’m the founder & maintainer of several open source projects, notably SourceHut, the Hare programming language, and Vim Classic, and I started but no longer work on several more that you might have heard of, such as sway, wlroots, aerc, and many others.
