The category labels use three equal opaque border sides and a square edge where the fourth side is absent. Their very large authored corner radii normalize to touching semicircles on the rounded edge. The first three columns retain that capsule geometry at integer and fractional origins. The fourth column controls the existing path with smaller, separated corner radii. The second row changes the height while preserving the other declarations. No text, images, fonts or scripts paint inside the visible viewport. This isolates border geometry from image sampling and from the original publisher font.
